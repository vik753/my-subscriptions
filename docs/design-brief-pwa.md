# Бриф на изменение дизайна: My Subscriptions → PWA (только Google)

Обнови прототип `design/Абонементы.dc.html`, `README.md` и скриншоты под новую платформу. Визуальный язык не меняется: токены, 4 схемы × светлая/тёмная, шрифт Inter, иконки Phosphor, радиусы, отступы, стиль кнопок (primary — только контур). Меняется платформа и часть функций.

## 1. Что изменилось в продукте

| Было                                          | Стало                                                                                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Нативное приложение iOS/Android               | **PWA**: веб-приложение, устанавливается на экран «Домой» из Safari или Chrome. Может открываться и на компьютере                     |
| Google Calendar **или** Apple Calendar        | **Только Google Calendar.** Приложение создаёт в аккаунте пользователя отдельный календарь «My Subscriptions» и работает только с ним |
| iCloud **или** Google Drive                   | **Только Google Drive** (скрытая папка приложения). Данные синхронизируются между устройствами пользователя                           |
| Push-вопрос через минуту после конца занятия  | **Уведомлений нет.** Вопрос «Вы были?» задаётся **при открытии приложения** по всем прошедшим занятиям без отметки                    |
| Напоминание о продлении: панель + уведомление | Только панель в приложении + пометка в событии Google Calendar                                                                        |
| Вход не нужен                                 | **Вход через Google обязателен** (первый экран)                                                                                       |
| Оценить в App Store / Google Play             | Сторов нет, пункт убрать                                                                                                              |

Сервера нет: приложение напрямую работает с Google Calendar API и Google Drive API.

## 2. Удалить

1. Всё, что связано с **Apple Calendar** и **iCloud**: пункты, иконки `apple-logo` и `cloud`, строки в `L`.
2. В форме создания/редактирования хобби — **блок «Calendar»** с двумя вариантами (Google / Apple).
3. В Settings — раздел **«Save data to»**.
4. В About — пункт **«Rate on App Store / Google Play»**.
5. **Баннер уведомления в стиле iOS** и кнопку прототипа «End session …» внизу экрана хобби.
6. Настройки прототипа, которые больше не нужны: `platform (auto/iOS/Android)`, `prompt delay`, `default calendar`.
7. Поле `calendar` в модели `Hobby` и `storage` в `Settings` (в README).

## 3. Новые экраны и состояния

### 3.1 Вход (первый запуск / выход из аккаунта)

- Иконка приложения 72px, название «My Subscriptions» 26px/500, подзаголовок 14px neutral-400.
- 3 коротких пункта о том, что умеет приложение (иконка + текст 14px): абонементы и остаток занятий · занятия в Google Calendar, оплаченные — зелёные · данные хранятся в вашем Google Drive.
- Primary-кнопка во всю ширину «Войти через Google» (`google-logo`).
- Под ней 12px neutral-500 — какие доступы запрашиваем: «Приложение видит только свой календарь "My Subscriptions" и свою скрытую папку в Google Drive. Другие события и файлы недоступны».
- Состояния: загрузка (кнопка неактивна + спиннер), ошибка («Не удалось войти. Попробуйте ещё раз»), отказ в доступе («Без доступа к календарю приложение не сможет создавать занятия» + кнопка «Дать доступ»).

### 3.2 Подсказка «Установите приложение»

Показывается, если приложение открыто во вкладке браузера, а не с экрана «Домой».

- Карточка над списком на Home (surface, radius 14, кнопка-крестик «закрыть»). Заголовок «Установите на экран "Домой"», текст — инструкция по платформе:
  - iOS: «Нажмите "Поделиться" `share-network` → "На экран Домой"».
  - Android / компьютер: кнопка «Установить» (системный запрос установки).
- Та же инструкция — отдельной строкой в Settings («Установить приложение»), пока приложение не установлено.

### 3.3 Отметка прошедших занятий при открытии (заменяет вопрос после занятия)

Занятие **ждёт ответа**, если время его окончания (начало + длительность) прошло, а отметки нет. Проверка — при каждом открытии приложения и возврате в него.

- **Одно такое занятие** → текущая панель «Вы были на занятии?» без изменений (мета «Спортзал · пт, 25 сентября, 18:00», кнопки «Я был» / «Не состоялось — перенести оплату»). Добавь ghost-кнопку «Позже».
- **Два и больше** → новая панель **«Отметьте прошедшие занятия»**:
  - Подзаголовок: «N занятий без отметки» (с учётом падежей).
  - Список по хронологии, **сначала старые** (порядок влияет на распределение оплат). Строка: название хобби 15px, дата и время 12px neutral-500, справа две компактные кнопки-переключателя: `check` «Был» / `x` «Не было». Пока не выбрано — обе в состоянии secondary.
  - Если хобби несколько — сгруппировать по хобби с подзаголовками.
  - Ссылка-ghost над списком: «Отметить все как посещённые».
  - Primary «Сохранить» (активна, когда отмечено хотя бы одно), ghost «Позже».
  - Если список длинный — панель на всю высоту с прокруткой, кнопки закреплены внизу.
- После сохранения: тост «Отмечено: N». Если у какого-то хобби остаток ≤ 1 — показать панель напоминания о продлении (3.5). Если таких хобби несколько — по очереди.
- «Позже» — панель не появляется до следующего открытия приложения, неотмеченные занятия видны на Home и в календаре (3.4).

### 3.4 Индикация неотмеченных занятий

- **Home, карточка хобби:** тег «Не отмечено: 2» (tag-accent). Если тегов два, «Не отмечено» идёт перед «Пора продлить». Нажатие на тег открывает панель 3.3 для этого хобби.
- **Hobby detail, календарь месяца:** новый стиль клетки для «ждёт ответа». Например, 1px контур accent + точка accent 4px в правом верхнем углу; время под числом остаётся. Он должен отличаться от «оплачено», «посещено» и «не оплачено». Нажатие — панель «Вы были?» для этого занятия.
- Легенда: добавить пункт «Без отметки».
- В блоке «Ближайшие занятия» такие занятия не показываются. Над ним строка-кнопка «2 занятия ждут отметки ›».
- «Следующее занятие» на карточке — первое **будущее** занятие без отметки (не прошедшее).

### 3.5 Напоминание о продлении

Панель без изменений. Дополнительно:

- Показывать при открытии приложения, если у хобби остаток ≤ 1 и напоминание не отложено.
- «Напомнить позже» откладывает до следующего дня.
- В Google Calendar в описание последнего оплаченного события добавляется строка «Последнее оплаченное занятие — пора продлить абонемент» (текст дай в `L`).

### 3.6 Статус синхронизации

Данные сначала сохраняются на устройстве, потом отправляются в Google. Нужен компактный индикатор:

- **Hobby detail:** строку «Synced with Google Calendar» заменить компонентом с состояниями:
  - `calendar-check` «Синхронизировано с Google Calendar»;
  - спиннер «Синхронизация…»;
  - `cloud-slash` «Нет сети — изменения отправятся позже»;
  - `warning` accent «Нужно войти снова» + ghost-кнопка «Войти».
- **Home:** в строке с датой под заголовком — маленькая иконка этого же статуса. Показывается только при ошибке или офлайн-режиме.
- Новые тосты: «Синхронизировано», «Нет сети. Изменения сохранены на устройстве».

### 3.7 Пустой Home

Нет хобби: иконка `ticket` 48px в accent-круге, заголовок 18px/500 «Пока нет абонементов», текст 14px neutral-400 «Добавьте первое хобби — занятия появятся в Google Calendar», primary «Добавить хобби» (`plus`).
